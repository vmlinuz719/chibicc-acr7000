ACR-7000 Relocation Types

For the ELF-like object format. S = symbol address, A = addend, P = address of the instruction or word being patched, DP = __dp_base. All addresses are word addresses.

Type Field Value Overflow check Used by
R_ACR_ADDR18 bits 0–17 (displacement) S+A fits a signed 18-bit field; an absolute address must be below 0400000 jmp label, calls f, ld x0, var, ld x0, tab(x1), @label, ldea/addea label, edit x1, $$shl
R_ACR_PCREL18 bits 0–17 with index mode 2 (.label) S+A−P signed 18-bit jmp .rd_wait and other hand-written code, when the target is in another section or unit
R_ACR_DPREL18 bits 0–17 with index mode 1 (_label) S+A−DP signed 18-bit ld x0, _var: references to data in the direct page
R_ACR_PAGE18 bits 0–17; bits 18–35 kept (S+A) >> 9 unsigned 18-bit (a 27-bit address always fits); low 9 bits of S+A must be zero Setting the direct page base in CW, e.g. cw: dw %page(__dp_base) with other CW bits (such as the IRQL) in the same word
R_ACR_HI18 bits 0–17 of ldeas (S+A) >> 17 bits 34 and 35 of S+A must agree (a 27-bit address always passes) ldeas x, %hi(sym)
R_ACR_LO17 bits 0–17 of addea (S+A) & 0377777 none (the result is always positive) addea x, %lo(sym)
R_ACR_WORD36 the whole word S+A, truncated to 36 bits none dw label: initialized pointers to word-aligned objects and functions, &a[3], and chibicc's address words for far objects
R_ACR_ADDR27 bits 0–26; bits 27–35 kept S+A 27-bit Exception and interrupt vectors, indirect words with auto-increment, hardware byte pointers, sch/rch/wch and clist channel words
R_ACR_HPTR36 the whole word (S << 1) + A none C short * initializers
R_ACR_CPTR36 the whole word (S << 2) + A none C char * and void * initializers

Notes

  • Addends. Use RELA-style relocations with an explicit addend: an 18-bit in-place field can't hold the addend for a 36-bit target. For R_ACR_HPTR36 and R_ACR_CPTR36 the addend is in the pointer's own units (halves or quarters).
  • cdata puts an unsigned 18-bit address in bits 0–17. It can reuse R_ACR_ADDR18's patch logic, but needs an unsigned overflow check (or its own type, R_ACR_ADDR18U).
  • R_ACR_WORD36 vs. R_ACR_ADDR27. WORD36 is plain C data, where &a[-1] must wrap at 36 bits. ADDR27 keeps the bits above the address field and must not carry into them.
  • HI18/LO17. ldeas shifts by 17, so the low part is never negative: no carry adjustment, and the two relocations need not be paired or adjacent. When the low part is zero the addea can be dropped.
  • __dp_base is defined by the linker and aligned to 512 words, since the hardware base is (CW bits 0–17) × 512. The _disp window is DP−0400000 to DP+0377777. Record it where a loader can find it, so a loader that sets CW itself uses the value the linker assumed.
  • PAGE18 with ldea works only for page numbers below 0400000 (addresses below 226); above that ldea sign-extends into the upper bits.
  • Not needed: I/O device numbers, byte sizes, shift counts and save masks (asm2 accepts no labels there); GOT/PLT/COPY types (no dynamic linking).
